# User Journey

Output: `docs/journeys/<project>/<journey-name>.md`

## Include

- Actor, goal, preconditions
- Step-by-step (UI + API calls)
- Screens/routes involved
- Data created or changed
- Failure paths and recovery
- Links to PRD, slices, tests

Use for onboarding, QA scenarios, and e2e test planning.
