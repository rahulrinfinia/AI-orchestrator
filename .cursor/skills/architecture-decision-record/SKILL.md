# ADR

Output: `docs/decisions/<project>/NNNN-<short-title>.md`

## Template

```markdown
# NNNN. Title

Date: YYYY-MM-DD
Status: Proposed | Accepted | Deprecated | Superseded by NNNN

## Context

## Decision

## Consequences

### Positive
### Negative
### Neutral
```

Number sequentially per project folder. Link from `docs/architecture.md`.
